## Exam Overview

The **Databricks Certified Machine Learning Professional (MLP-101)** exam verifies your ability to architect, operationalize, scale, and govern enterprise-grade machine learning pipelines on the Databricks Lakehouse Platform.

| Exam Parameter | Official Specification |
| --- | --- |
| **Official Name** | Databricks Certified Machine Learning Professional |
| **Exam Code** | `MLP-101` |
| **Total Questions** | 59 Multiple-Choice & Multi-Select Questions |
| **Time Allowed** | 120 minutes |
| **Passing Score** | ~70% (Scaled evaluation via Webassessor) |
| **Standard Cost** | $200 USD (Discounted to ~$140 USD via approved vouchers) |
| **Delivery Method** | Online Proctored or In-Person Kryterion/Webassessor Test Center |
| **Prerequisites** | Machine Learning Associate recommended; 1–2+ years production Databricks ML experience |
| **Credential Validity** | 2 Years |

## Who Should Take It

This exam is designed for Senior Machine Learning Engineers, Data Scientists, MLOps Architects, and AI Engineers responsible for scaling models, building robust deployment strategies, automating retraining pipelines, and ensuring ML governance across multi-environment workspaces.
